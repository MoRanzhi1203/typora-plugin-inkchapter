# Typora 墨章插件测试模板说明

本目录包含 8 篇不同类型的 Markdown 文档，用于测试：

- H1–H6 标题编号；
- H1 编号开关；
- 固定编号预设；
- 自定义多级组合格式；
- 标题有效级数范围；
- 超范围标题限制；
- 特殊标题取消编号；
- 侧栏大纲编号同步；
- 标题新增、删除、移动、升降级；
- 重复标题、长标题、中英文标题；
- 代码块、公式、表格、引用、列表对大纲识别的影响。

## 推荐测试顺序

1. 打开 `01-中文学术论文模板.md`，测试摘要、引言、总结、参考文献、附录等特殊标题。
2. 打开 `02-技术博客模板.md`，测试代码块和深层标题。
3. 打开 `03-项目报告模板.md`，测试中文章节式编号。
4. 打开 `04-课程讲义模板.md`，测试多级教学结构。
5. 打开 `05-中英双语论文模板.md`，测试中英文混合标题。
6. 打开 `06-深层级结构压力测试.md`，测试 H1–H6。
7. 打开 `07-重复标题与特殊标题测试.md`，测试同名标题和单标题编号覆盖。
8. 打开 `08-标题有效级数限制测试.md`，测试 H1–H4 等硬限制。

## 注意

这些文档仅用于插件测试，不代表正式论文或报告内容。
