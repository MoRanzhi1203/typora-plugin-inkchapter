# 测试指南

## 测试环境

测试 vault 位于 `test/vault/`，包含预配置的 Typora 环境和测试文档。

## 启动测试环境

```bash
pnpm build:dev
```

Typora 自动打开 `test/vault/doc.md`。

## 测试检查清单

### 基础功能
- [ ] 打开文档后标题自动显示编号
- [ ] 关闭「启用标题编号」开关后编号消失
- [ ] 开关 H1 可见性后编号正确适配
- [ ] 编辑标题文本后编号实时更新

### 预设样式
- [ ] 切换到十进制层级预设：1, 1.1, 1.1.1
- [ ] 切换到中文章节预设：第一章, 第一节, 一、
- [ ] 切换到中文大纲预设：一、, (一), 1.
- [ ] 切换到罗马数字预设：I, II, III

### Custom 编辑器
- [ ] 选择「自定义」展开编辑面板
- [ ] 格式片段可拖拽排序
- [ ] 插入字面文本和上级引用
- [ ] 预览与实际编号一致

### 目录编号
- [ ] 打开侧栏目录面板，标题显示编号
- [ ] 编辑后目录编号实时更新
- [ ] 切换文档后目录编号正确

### 级数范围
- [ ] 设置 maxLevel=3 后 H4-H6 不编号
- [ ] Ctrl+4 创建 H4 被阻止
- [ ] 粘贴超范围 ATX 行被转换

### 特殊标题
- [ ] 「摘要」「Abstract」标记为不编号
- [ ] 不编号标题不影响后续计数器

### 文档级配置
- [ ] 文档 A 自定义配置不影响文档 B
- [ ] 恢复默认清除文档覆盖
- [ ] 切换文档后配置各自保持

## 验证证据

每次测试后检查 `test/vault/.typora/inkchapter-runtime-load.json` 确认：
- `initializationCount` 合理（不重复增加）
- `buildMarker` 匹配当前版本
- `ribbonInjected` 为 false
