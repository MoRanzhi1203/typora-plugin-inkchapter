## 2. 配置分层

`image-config-layers.ts`：

1. **公开默认**：`DEFAULT_IMAGE_SETTINGS`，`uploadService = none`，所有路径为空。
2. **本机用户配置**：插件设置（Git 工作区之外），可覆盖服务、路径、配额。
3. **项目级选项**：`parseProjectImageOptions` 仅允许：
   - `schemaVersion`
   - `referenceMode`（`local-relative | remote-url`）
   - `cacheMode`（`off | smart | manual`）
   - 其他键（Token、仓库、绝对路径、上传服务）一律拒绝。
4. **当次操作覆盖**：`resolveEffectiveImageConfig(base, overrides)` 合并并标注来源（`public-default / user / operation`），不修改 `base`。

安全约束：

- GitHub 覆盖仍要求已启用的本机 Profile；否则回落 `none`，来源不标记为 `operation`。
- 路径与凭据不进入项目级共享选项。

## 3. 设置页

在既有「墨章 · 图片」页新增：

| 区块 | 内容 |
|---|---|
| 上传服务 | 无 / GitHub；无有效远程配置时拒绝切换 |
| 存储路径与配额 | 缓存模式、缓存目录、上限（默认 512 MB）、离线目录、上传暂存、资产数据库 |
| 有效配置与来源 | 按钮「刷新有效配置」；显示运行时解析路径、来源标记、缓存占用、图库状态、Profile 数量 |
| Typora 原生插图 | 只列出六种方式并引导到 Typora 首选项；不读取、不伪装同步状态 |
| 项目整理与离线 | 说明需要文档上下文、先预览后执行，设置页不会自动迁移或改写 |
| 图库中心 | 只读概览说明；明确不新增漂浮标记、不影响既有图号/题注 |

路径输入规则：

- 留空 = 运行时系统默认（`LOCALAPPDATA` / `TEMP` / 插件数据目录）。
- 自定义必须是绝对路径且不含 `..`；非法输入由读取侧丢弃并提示。
- 解析阶段不创建目录；占用统计由只读 `inspectDirectoryUsage` 完成。
