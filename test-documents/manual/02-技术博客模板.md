## 数据读取

### 读取 CSV

```python

df = pd.read_csv("data.csv")
print(df.head())
```

### 检查数据类型

```python
print(df.dtypes)
```

## 数据清洗

### 缺失值

#### 缺失值检测

```python
print(df.isna().sum())
```

#### 缺失值填补

##### 数值列

```python
df["value"] = df["value"].fillna(df["value"].median())
```

##### 类别列

```python
df["category"] = df["category"].fillna("Unknown")
```

### 异常值

#### IQR 方法

$$
IQR=Q_3-Q_1
$$

###### 极端异常值

极端异常值可以单独标记，而不是直接删除。

## 数据可视化

### 折线图

```python
import matplotlib.pyplot as plt

plt.plot(df["date"], df["value"])
plt.show()
```

### 散点图

```python
plt.scatter(df["x"], df["y"])
plt.show()
```
